# Battleship
This is a implementation of the classic game Battleship done in C#. The game is played on a 5x5 grid, where each player has a fleet of ships that they must strategically place on the grid. The objective is to sink all of the opponent's ships by guessing their locations on the grid first.

## Online
The idea behind this project was to be able to create a console driven server using TCP sockets, that could handle multiple clients at the same time. The clients would be able to connect to the server and play against each other in real-time. The server would manage the game state and ensure that the rules of the game are followed.
